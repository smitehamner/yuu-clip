Speaker model
SpeechBrain is included with YuuClip - no HuggingFace account or token needed. The speaker model (~80 MB) downloads automatically the first time you run Detect Speakers.
How readily two moments of speech are treated as different people within one recording. Lower splits into more speakers; higher merges more together. 0.85 is the default. If one person keeps getting split into many speakers, raise it; if two people are being merged, lower it.
A voice that speaks for fewer than this many seconds in a recording is treated as background noise or crosstalk and folded into the nearest speaker. Raise it if you still get spurious extra speakers; lower it (or set 0 to turn it off) to keep every brief voice. 10 seconds is the default.
How similar a voice must be to re-attach to an already-named speaker on Re-detect Speakers. Higher is stricter - fewer wrong matches, but more voices re-listed as new "Speaker N" to re-confirm. 0.75 is a safe default; lower it if named speakers keep coming back unnamed.
How sure the app must be that a voice in a new recording is the same person you already named in another one. Higher = fewer wrong matches. Matches are only ever suggested - you confirm them in People, nothing is merged automatically. 0.80 is a safe default.

Hot-words
Boost a clip's score when a phrase is spoken - great for running gags or catchphrases. Leave one Global to apply everywhere, or scope it to a world context so it only affects recordings tagged with that context. Saved instantly; use Rescan current recording from the confirmation toast to apply changes to a recording's existing clips without a full re-score.
Sensitive Content
Flag clips containing names, personal info, or language you want to catch before sharing - kept completely separate from scoring, so it never changes a clip's score, only warns. Privacy Terms are names or personal info you don't want in shared clips; Censor Words are language to flag before posting to restricted platforms. Leave one Global to flag everywhere, or scope it to a world context to flag only recordings tagged with that context. Saved instantly and applied to every clip right away.
