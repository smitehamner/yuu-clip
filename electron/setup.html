LLM scoring

A local language model writes each clip's description and adds a semantic read on top of the scoring. Setting one up is the normal first step - a one-click download that runs in the background. Even before it finishes, clips are still found and scored from laughter, excitement, keywords, and scene / on-screen action.
Downloads a model that runs on your own machine - free, private, and the source of the best results. A one-time download of about 4.7 GB that happens in the background after you launch, so you can start using YuuClip right away.
Skip the model download for now. Clips are still found and scored from audio and on-screen signals - you just won't get written descriptions or the model's semantic read. You can set up local AI anytime in Settings.

Content type

Tune scoring for the kind of content you make. This sets sensible funny / dramatic / action weights and points the AI at what makes a good highlight for that style. Leave it on Generic if you're not sure - you can change it any time in Settings.
