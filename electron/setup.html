LLM scoring — choose one
An AI model reads the transcript to rate how funny, dramatic, or action-packed each clip is, and writes descriptions. Without it, clips are still found using audio energy and scene detection — but they won't get quality scores or descriptions. Not ready to decide? You can set this up any time in Settings (⚙).
Heads-up on download size: running a model on your own machine is a one-time download of roughly 4–9 GB (the recommended model is ~4.7 GB). The Claude API needs no download but sends transcripts to Anthropic and is billed per use.
